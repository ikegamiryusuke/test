# デジタルスタンプラリー サンプル

このリポジトリには、Google Apps Script(GAS) と Google スプレッドシートで動作する簡単なスタンプラリーアプリのソースを収めています。`gas_app` フォルダのファイルをそのまま Apps Script プロジェクトへコピーすればすぐに使えます。ニックネームと4桁の誕生日で登録し、次回以降は同じ情報でログインするだけで進捗がシートからダウンロードされます。

## セットアップ手順
1. 新しいスプレッドシートを作成し、URL 中 `/d/` と `/edit` の間にある ID を控えます。
2. script.google.com で空のプロジェクトを作成し、`gas_app` 内の `Code.gs`、`index.html`、`main.html`、`style.html` をそれぞれ同名のファイルとして貼り付けます。
   - Apps Script のファイル名欄には拡張子を含まない名前 (`index` など) を入力してください。
3. `Code.gs` の `SPREADSHEET_ID` 定数を手順1で取得した ID に書き換えます。
4. メニューの **デプロイ** → **新しいデプロイ** を選び、種類を Web アプリにして公開します。公開後に表示される URL がアプリのアクセス先になります。
5. 上記 URL へアクセスし、ニックネームと4桁の誕生日を入力して新規登録またはログインします。
   - 一度登録した後は同じ情報を入力するだけで進捗がダウンロードされます。
   - 誕生日は必ず4桁の数字で入力してください。
   - ニックネームは内部的に URL エンコードされ、対応する行番号が ScriptProperties に保存されます。
   - 旧バージョンで保存した `row_ニックネーム` 形式のキーも読み込む互換処理があります。

## 使い方
1. ログインまたは新規登録を選ぶと入力画面が表示されます。
2. ニックネームと誕生日4桁を入力して送信すると、登録済みであれば進捗を取得し、未登録なら自動で登録されます。
3. スポットで手に入れた暗号をダイヤルで入力してスタンプを集めましょう。

## 動作概要
- スプレッドシートには `Users` というシートが作成され、`Nickname` `Birthday` `Progress` の3列で管理します。同じニックネームは登録できません。
- スタンプコードと画像 URL は `STAMPS` 配列で定義されており、初期値は `1234`、`5678`、`9999` の3つです。
- 背景画像は `BACKGROUND` 定数、スタンプ画面の背景は `STAMP_BACKGROUND` で設定します。
- スタンプ枠は三角形に配置され、未取得の枠には「?」が表示されます。ダイヤル式で4桁のコードを入力し、正解なら中央に「STAMP!」が現れます。全て集めると「COMPLETE!!」が表示されます。

## 安定運用のために
- 登録時は `LockService` を使ってシートをロックし、複数の利用者が同時にアクセスしても重複登録が起きないようにしています。
- これらの処理は無料プランの実行時間内に収まるため、1日500人規模でも問題なく利用できます。

## 付属スクリプトについて
`main.py` は GAS デプロイ後の動作確認を行うだけのサンプルで、アプリ本体には不要です。実行には `requests` ライブラリが必要なため、環境によっては `pip install requests` を行ってください。
